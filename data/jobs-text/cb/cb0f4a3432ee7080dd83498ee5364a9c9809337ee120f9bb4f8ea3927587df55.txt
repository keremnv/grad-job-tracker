&lt;h3&gt;Overview&lt;/h3&gt;
&lt;p&gt;We&#39;re looking for an Agentic Systems Engineer, to work on systems that haven&#39;t existed before. Think of an Agentic Coach that navigates the unpredictability of human biology, or the software architecture behind a fully automated Dark Lab. These aren&#39;t chatbots waiting for questions. They&#39;re proactive systems that maintain world models, interpret human intent, and intervene before the user knows to ask. These systems create genuine impact for clients tackling problems no one else can solve.&lt;/p&gt;
&lt;p&gt;Building them means designing and wiring agent harnesses: layered architectures that span from sensor-edge reasoning to high-level planning, backed by stateful multi-turn reasoning, persistent per-user memory, and robust evaluation pipelines.&lt;/p&gt;
&lt;p&gt;You&#39;ll work in two directions at once. Internally, you&#39;ll use the latest AI tools to sharpen how we build, prototype, and ship. Externally, you&#39;ll deliver the breakthrough systems our clients deploy, designed to move from prototype to production at pace.&lt;/p&gt;
&lt;p&gt;There&#39;s no single technology stack. You&#39;ll work with agents, multi-agent systems, and the latest generative AI tools, but your work will always be grounded in solid software engineering. Expect to build scalable distributed systems in core languages like Python and TypeScript, leveraging frameworks such as NextJS and Pydantic, agent orchestration tools (LangGraph, CrewAI), and protocols like MCP. You&#39;ll deploy on cloud platforms (AWS, GCP, Azure) using Docker, Kubernetes, and infrastructure-as-code, backed by rigorous CI/CD and observability (OpenTelemetry, Prometheus).&lt;/p&gt;
&lt;p&gt;Due to the clients we work with, you must be eligible for UK security clearance.&lt;/p&gt;
&lt;h3&gt;What you&#39;ll be doing&lt;/h3&gt;
&lt;ul&gt;
&lt;li&gt;AI System Architecture: Designing and implementing the logic for autonomous systems, including maintaining world models, integrating multimodal sensing, and building real-time human-machine interaction loops.&lt;/li&gt;
&lt;li&gt;Infrastructure &amp;amp; Production Engineering: Designing the underlying software for scalable, secure, and observable cloud deployments. You will apply the engineering rigor required to take experimental AI from concept to robust live launch.&lt;/li&gt;
&lt;li&gt;Rapid Client Prototyping: Driving a demo-first delivery model. You will focus on fast experimentation to actively show tangible value and working software to clients, rather than describing it in slide decks.&lt;/li&gt;
&lt;li&gt;Domain Translation &amp;amp; Integration: Partnering directly with deep-tech subject matter experts (like biologists and roboticists) to apply software solutions to complex physical constraints.&lt;/li&gt;
&lt;/ul&gt;
&lt;h3&gt;What you need to succeed:&lt;/h3&gt;
&lt;ul&gt;
&lt;li&gt;Applied AI Expertise: You have hands-on experience utilising multi-agent frameworks, long-term memory systems, RAG pipelines, vector/graph databases, and reasoning-loop patterns (such as ReAct and Chain-of-Thought).&lt;/li&gt;
&lt;li&gt;Core Software Fluency: You possess strong programming skills in Python and TypeScript, coupled with practical experience in cloud engineering, containerisation, and modern DevOps. You know that great agents still require rock-solid software foundations.&lt;/li&gt;
&lt;li&gt;High Tolerance for Ambiguity: You are energised by uncertainty and shifting targets. You treat changing requirements as a normal part of frontier work, and you know exactly when to ship a rough prototype to learn quickly versus when to slow down for architectural rigour.&lt;/li&gt;
&lt;li&gt;Cross-Disciplinary Communication: You can seamlessly navigate the gap between code and reality, collaborating with clients, roboticists, and scientists to clearly deliver the &quot;art of the possible.&quot;&lt;/li&gt;
&lt;/ul&gt;
